## 1. 项目概述

**DeepSeek Chat** 是一个基于 DeepSeek API 的智能对话客户端，提供 **命令行交互模式**、**Web UI 模式** 和 **桌面应用模式** 三种使用方式。项目使用 Python 编写，前端采用纯 HTML/CSS/JavaScript，后端使用 Flask 框架。

### 1.1 核心功能

- 💬 多会话管理（WebUI 侧边栏历史列表）
- 🖥️ 三种运行模式：命令行、Web 浏览器、原生桌面窗口
- 🧠 长期记忆系统（记住/忘记指令，持久化到 JSON 文件）
- 📝 对话历史自动保存（Markdown 格式）
- 🔄 流式输出（SSE - Server-Sent Events）
- 🌓 深色/浅色主题切换
- ⚙️ 运行时配置热修改（通过 WebUI 设置对话框）
- 🔑 API 密钥、模型、温度等参数可配置

### 3.2 `deepseekchat.py` — 核心引擎

**类: `DeepSeekChat`**

这是项目的核心模块，封装了所有业务逻辑，可被 `main.py` 或 `app.py` 调用。

**初始化流程:**
1. 从 config 字典读取 API、模型、对话、UI、记忆配置
2. 创建 OpenAI 客户端
3. 从 `memories.json` 加载长期记忆
4. 构建 system messages（含记忆注入）
5. 创建会话历史 Markdown 文件

**主要方法:**

| 方法 | 说明 |
|------|------|
| `send_message(user_input)` | 发送消息，流式输出到终端，自动处理记忆命令 |
| `run_interactive()` | 启动交互式对话循环 |
| `clear_context()` | 清空对话上下文（保留 system prompt 和记忆） |
| `save_chat_history(title)` | 保存对话历史到 JSON 文件 |
| `_add_memory(content)` | 添加长期记忆（去重）并持久化，注入即时指令 |
| `_remove_memory(content_or_index)` | 按内容或序号删除记忆 |
| `_show_memories()` | 显示所有记忆 |
| `_rebuild_messages()` | 重新构建 messages 列表（保留历史，更新 system） |
| `_build_system_messages()` | 构建 system prompt + 记忆注入 |

**内置命令（交互模式）:**

| 命令 | 功能 |
|------|------|
| `exit` / `quit` | 退出对话 |
| `/clear` | 清空上下文 |
| `/save` | 保存对话历史 |
| `/memories` | 查看长期记忆 |
| `记住：xxx` / `记住:xxx` | 添加长期记忆 |
| `忘记：xxx` / `忘记:xxx` | 删除长期记忆（支持序号或内容匹配） |

**关键设计:**
- 记忆系统通过 `system` 角色消息注入上下文
- 添加记忆时会立即插入一条 `[系统即时指令]` 消息增强即时效果
- 所有对话记录以 Markdown 格式追加到 `history/session_*.md`

### 3.4 `app.py` — Flask Web 后端

**功能:** 提供 WebUI 的 REST API 和页面渲染。

**路由表:**

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/` | 渲染主页面 (`chat.html`) |
| GET | `/api/config` | 返回前端配置（模型列表） |
| GET/POST | `/api/model` | 获取/切换当前模型 |
| GET | `/api/sessions` | 列出所有历史会话 |
| POST | `/api/sessions/load` | 加载指定历史会话 |
| POST | `/api/sessions/new` | 创建新会话 |
| DELETE | `/api/sessions/<filename>` | 删除指定会话（防路径穿越） |
| POST | `/api/chat/<session_id>` | 发送消息，返回 SSE 流式响应 |
| GET/POST | `/api/settings` | 获取/保存配置（写入 config.yaml） |
| GET/POST | `/api/memories` | 获取/保存长期记忆列表 |
| DELETE | `/api/memories/<index>` | 删除指定序号的记忆 |

**关键设计:**
- 会话管理: 内存字典 `_sessions` + 文件持久化（Markdown）
- 流式输出: 使用 `Response` + `stream_with_context` + SSE 格式
- 配置热重载: 保存设置后重新加载 config.yaml 并更新全局变量
- `DATA_DIR` 处理: 支持 PyInstaller 打包后的路径重定向

**会话生命周期:**
1. 创建新会话 → 生成 `session_时间戳.md` 文件头
2. 用户发送消息 → 追加到 Markdown 文件 + 发送 API 请求
3. AI 回复 → SSE 流式推送到前端 + 追加到 Markdown 文件
4. 加载历史 → 解析 Markdown 文件恢复消息列表

## 4. 数据流

### 4.1 消息发送流程（WebUI 模式）

```
用户输入 → chat.html (Fetch API) 
    → POST /api/chat/<session_id> (Flask)
        → app.py 处理: 追加用户消息到 Markdown
        → OpenAI API 流式请求
        → SSE 流式返回 (data: {content, done})
    → chat.html 解析 SSE → 实时渲染消息
    → 流结束后: 追加 AI 回复到 Markdown + 更新会话列表
```

### 4.2 配置保存流程

```
WebUI 设置对话框 → POST /api/settings
    → app.py: 更新 config.yaml + 热重载全局变量
    → 返回 {success: true}
    → 前端: 显示 Toast 提示 + 刷新模型列表 + 应用主题
```

### 4.3 记忆系统数据流

```
用户输入 "记住：xxx"
    → deepseekchat.py: _is_remember_cmd() 检测
    → _add_memory(): 去重 → 追加到 self.memories → 写入 memories.json
    → _rebuild_messages(): 重新构建 system messages（含记忆注入）
    → 插入即时指令消息增强效果

下次启动:
    → __init__ → _load_memories() → _build_system_messages() → 记忆自动注入
```

## 7. 注意事项 & 已知设计

1. **WebUI 模式未实现记忆命令**：`app.py` 中的聊天逻辑没有检测"记住：/忘记："命令，WebUI 用户无法通过对话管理记忆，只能通过设置页面启用/禁用记忆功能。
2. **`app.py` 和 `deepseekchat.py` 有代码重复**：两处都实现了相似的记忆加载、system message 构建、Markdown 历史写入逻辑。`app.py` 是独立实现的，没有复用 `DeepSeekChat` 类。
3. **前端无框架**：纯原生 JS，适合轻量运行，但扩展复杂功能时需手动管理状态。
4. **API 密钥硬编码风险**：`config.yaml` 中包含明文 API 密钥，应注意不要提交到版本控制。
5. **历史文件格式**：Markdown 格式，解析依赖正则表达式 `### [用户/DeepSeek]` 块标记。
6. **打包后数据目录**：PyInstaller 打包后，配置/历史/记忆文件将存储在 exe 所在目录。

## 2. 🔑 配置 API 密钥

DeepSeek Chat 需要调用 DeepSeek API，你必须拥有有效的 API 密钥。

### 2.1 获取密钥
- 访问 [DeepSeek 官网](https://platform.deepseek.com/)

### 2.2 写入配置文件

```yaml
api:
  api_key: "sk-你的实际密钥"   # 替换为你的密钥
  base_url: "https://api.deepseek.com"
```
保存即可。其他参数（模型、温度等）保持默认即可，也可稍后通过 WebUI 设置。

## 3. 🚀 运行方式（三种任选）

### 3.1 方式一：命令行模式（CLI）

适合喜欢终端操作、高效率的用户。

```bash
python main.py
```
启动后进入交互模式，你可以直接输入问题：
```
你: 你好，请介绍一下你自己。
DeepSeek: 您好！我是 DeepSeek Chat，一个智能对话助手……

你: /help   # 查看所有内置命令
```

**常用内置命令：**
| 命令 | 功能 |
|------|------|
| `exit` / `quit` | 退出对话 |
| `/clear` | 清空当前上下文（不丢失记忆） |
| `/save` | 手动保存对话记录到 `history/` 目录 |
| `/memories` | 查看所有长期记忆 |
| `记住：xxx` | 添加一条长期记忆（系统会自动注入） |
| `忘记：xxx` | 删除指定记忆（支持序号或内容） |

**单次问答模式**（适合脚本调用）：
```bash
python main.py --single "用Python写一个冒泡排序"
```
加上 `--save` 可以同时保存这次对话历史。

**其他有用参数：**
```bash
python main.py -m deepseek-v4-pro -t 0.9   # 使用 pro 模型，高创造力
python main.py --no-thinking                # 禁用思维链（回复更快但思考过程不可见）
```
运行 `python main.py --help` 查看全部参数。

---

### 3.2 方式二：WebUI 模式（浏览器）

功能最丰富，适合日常使用。

```bash
python app.py
```
启动后终端显示：
```
 * Running on http://127.0.0.1:5000
```
打开浏览器访问 `http://localhost:5000`。

**界面操作：**
- **左侧边栏**：所有历史会话列表，点击切换，点击“✚ 新对话”创建新会话，右侧❌删除。
- **主聊天区**：输入消息按 Enter 发送，Shift+Enter 换行。AI 回复流式显示，代码块自动高亮并附带“复制”按钮。
- **顶部状态栏**：显示当前模型，点击可快速切换（`deepseek-v4-flash` 与 `deepseek-v4-pro`）。
- **右上角按钮**：
  - 🌓 切换深色/浅色主题（自动保存偏好）
  - ⚙️ 打开设置对话框

**设置对话框详解：**
点击 ⚙️ 后弹出侧边导航+右侧面板的对话框：

| 导航项 | 可设置内容 |
|--------|------------|
| API | API 密钥、Base URL |
| 模型 | 模型名称、推理努力度（low/medium/high）、温度（0~2）、Max Tokens |
| 对话 | 系统提示词、是否启用思维链、是否保存历史 |
| 记忆 | 启用/禁用长期记忆、自动注入、查看/添加/编辑/删除记忆 |
| 界面 | 默认主题、是否显示 Token 用量 |

设置会实时保存到 `config.yaml`，下次启动自动生效。

**多会话管理细节：**
- 每次新对话自动在 `history/session_时间戳.md` 创建文件。
- 历史会话可通过侧边栏**加载**，恢复全部聊天上下文（包括之前的消息和 AI 回复）。
- 删除会话不会删除文件（前端只清理列表），如需彻底删除需手动删除 `.md` 文件。

## 4. 🧠 长期记忆系统详解

记忆系统让 AI 能够记住重要的信息，并在后续对话中自动调用。

### 4.1 命令行模式（CLI）使用记忆
- **添加记忆**：输入 `记住：我的名字是小明`
- **查看记忆**：输入 `/memories`
- **删除记忆**：输入 `忘记：1`（按序号）或 `忘记：小明的名字`（按内容模糊匹配）
- 记忆会持久化到 `memories.json` 文件，下次启动自动加载。

### 4.2 WebUI 模式使用记忆
WebUI 不支持通过聊天命令管理记忆，但可以通过 **设置对话框 → 记忆** 面板手动管理：
- 勾选“启用记忆”并“自动注入”，AI 在每次回答前都会参考所有记忆。
- 可以在文本框中直接添加、编辑、删除记忆条目，保存后立即生效。

### 4.3 记忆工作原理
- 每次添加记忆，系统会立即重建 system message，将记忆内容注入为系统指令。
- 同时插入一条“即时指令”消息，让 AI 马上关注新记忆。
- 所有记忆以 JSON 数组格式保存在 `memories.json` 中，每条记忆是一个字符串。

## 5. 📁 文件与数据管理

### 5.1 配置文件
- `config.yaml`：手动编辑或通过 WebUI 修改。记录 API 密钥、模型参数、界面偏好等。
- 注意：**不要将含真实密钥的 config.yaml 上传到公开仓库**。

### 5.2 记忆文件
- `memories.json`：长期记忆存储，纯文本 JSON 格式，可手动编辑（修改后需重启应用）。

### 5.3 对话历史
- 所有对话记录保存在 `history/` 目录下，命名规则 `session_YYYYMMDD_HHMMSS.md`。
- 格式为 Markdown：`### 用户` 与 `### DeepSeek` 交替。
- 你可以用任何 Markdown 编辑器查看或分享这些记录。
- 如果你不想自动保存，可在设置中关闭“保存历史”。

## 6. 🛑 常见问题 & 排错

### 6.1 启动时报错 `ModuleNotFoundError`
- 确保已安装所有依赖：`pip install -r requirements-desktop.txt`
- 如果报 `pywebview` 找不到，而你不打算使用桌面模式，可以忽略该错误，只运行 `python main.py` 或 `python app.py`。

### 6.2 API 请求失败或返回“无效密钥”
- 检查 `config.yaml` 中 `api_key` 是否填写正确，注意不要有引号多余空格。
- 确保 API 密钥未被禁用且账户有足够配额。

### 6.3 WebUI 页面空白或无法连接
- 确认 Flask 启动时显示的地址和端口（默认为 `5000`）。
- 如果端口被占用，可以在启动前修改 `app.py` 中的 `port` 变量为其他值（如 `5001`）。

### 6.4 桌面窗口闪退
- 尝试先手动运行 `python app.py` 确保 WebUI 能正常启动，再运行 `python desktop_app.py`。
- 如果是因为缺少 `pywebview`，请安装完整依赖。

### 6.5 如何更新模型或修改参数？
- 最简单：在 WebUI 中点击 ⚙️ 设置，修改后点击“保存”，无需重启。
- 也支持直接编辑 `config.yaml` 后重启应用。

## 7. 💡 进阶技巧

### 7.1 使用不同的系统提示词
你可以为 AI 设定独特的角色，例如：
```yaml
# config.yaml
chat:
  system_prompt: "你是一个精通 Python 与数学的助教，回答要简洁专业，对于代码问题优先给出示例。"
```
或通过命令启动时指定：
```bash
python main.py -s "用猫娘语气和我说话～"
```

### 7.2 利用思维链（CoT）
当 `thinking_enabled: true` 时，AI 在正式回答前会显示思考过程（类似 o1 模型的“推理链”）。如果你只需要答案，可以关闭它：
```bash
python main.py --no-thinking
```
或 WebUI 设置中取消“启用思维链”。

### 7.3 批量处理任务
使用 CLI 的单次模式，可以结合 shell 脚本实现批量问答：
```bash
for query in "问题1" "问题2" "问题3"; do
    python main.py --single "$query"
done
```

### 7.4 自定义代码块样式
如果你熟悉 CSS，可以编辑 `templates/chat.html` 中 `.code-block` 相关样式，调整背景色、字体、按钮颜色等。
